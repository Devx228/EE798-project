attention's forward time grows $\sim3\times$ per doubling from 4k (entering its quadratic regime) while the
SSM's grows $2\times$, extrapolating to a crossover near 32k tokens -- beyond this GPU's memory for our

ship fused kernels. (2) Memory: the chunked implementations materialise $L\times L$ decay masks and
einsum intermediates, so they use more memory than FlashAttention here. (3) Decode: the KV cache grows
$64\times$ (512\,KB$\to$32\,MB) while per-token latency rises only 17\%; at this scale decoding is bound by
kernel-launch overhead, so the constant-size state wins on memory, not (yet) on latency. (4) Triton:
1.3--1.5$\times$ faster and 4.8$\times$ less memory than chunked PyTorch, but only $\sim$9\,GB/s
($\approx5\%$ of peak bandwidth): the time loop is sequential and only $b\cdot H\cdot P/B_P=64$ programs run,
so the kernel is latency-bound -- the motivation for Mamba-2's matmul-based SSD algorithm.}
