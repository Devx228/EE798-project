# Report: how to build

Overleaf: New Project -> Upload Project -> choose the zip. Set the compiler to pdfLaTeX (default) and
the main document to `main.tex`.

Locally (TeX Live / MiKTeX):

    latexmk -pdf main.tex        # or: pdflatex main && bibtex main && pdflatex main && pdflatex main

Layout:

    main.tex              preamble, title, section order
    sections/*.tex        one file per section required by the course guidelines
    figures/*.pdf|png     generated by scripts/plot_results.py and scripts/inspect_rotation.py
    tables/*.tex          generated by scripts/plot_results.py (re-run the script after new results)
    refs.bib              references (entries marked TODO need checking)

Red [TODO: ...] notes mark what still has to be written. The notes contain the numbers and the intended
interpretation; replace them with your own text. To hide every remaining note in a draft build, change
the \todo definition in main.tex to \newcommand{\todo}[1]{}.
